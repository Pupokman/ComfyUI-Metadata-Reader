# ComfyUI Metadata Reader v4.4

## Русский

**Скачивай файл `ComfyUI-Metadata-Reader-v4.4.html`.** Открой его в современном браузере — установка и интернет не нужны.

Архивы **Source code (zip)** и **Source code (tar.gz)** GitHub добавляет автоматически. Для обычного использования они не нужны.

### Что вошло в v4.4

- полноценный переключатель русского и английского языка;
- вычищенная русская локализация без канцелярита и машинных формулировок;
- естественная английская локализация, а не дословная калька;
- большая и удобная область перетаскивания файла;
- тёмная сине-фиолетовая тема и классическая компоновка;
- чтение метаданных из изображений, видео, аудио и других контейнеров;
- поддержка API prompt, workflow, вложенных subgraph и нестандартных значений вроде `NaN`;
- быстрый разбор больших медиафайлов без загрузки всего видео в память;
- копирование сводки, поиск, экспорт workflow и полного metadata JSON.

Все файлы обрабатываются локально в браузере и никуда не отправляются.

## English

**Download `ComfyUI-Metadata-Reader-v4.4.html`.** Open it in a modern browser; no installation or internet connection is required.

GitHub adds the **Source code (zip)** and **Source code (tar.gz)** archives automatically. They are not needed for normal use.

### Included in v4.4

- complete Russian and English interface switching;
- revised Russian copy without stiff or machine-written wording;
- natural English localization instead of a literal translation;
- a large, convenient file drop area;
- a dark blue-purple theme with the classic layout;
- metadata extraction from images, videos, audio files, and other containers;
- support for API prompts, workflows, nested subgraphs, and non-standard values such as `NaN`;
- fast scanning of large media files without loading the entire video into memory;
- summary copying, search, workflow export, and complete metadata JSON export.

Files are processed entirely in the browser and are never uploaded.
